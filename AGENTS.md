# The Hidden Extremes: AI Project Instructions

## Objective

Develop a first-place-caliber entry for the 2027 TSA High School Data Science and Analytics National Conference.

## Mandatory Standards

- Follow the current official TSA guidelines and target every available rubric point.
- Benchmark work against all accessible, verified historical winners and national finalists.
- Account for historical changes in competition themes and guidelines.
- Conduct comprehensive scientific literature research using original, credible publications.
- Identify opportunities for stronger originality, validation, methodology, visualization, and scientific communication.
- Independently verify previous AI-generated recommendations before implementing them.
- Never fabricate results, citations, placements, or claims of novelty.
- Clearly distinguish pilot results, mock outputs, confirmatory findings, and proposed work.
- Protect withheld evaluation measurements against data leakage.
- Do not change the frozen scientific protocol without documenting the reason and obtaining both partners' approval.
- Maintain reproducible code, source manifests, validation tests, and transparent documentation.
- Review the current project status and relevant decision records before making changes.
- Evaluate completed competition materials against the official rubric from the perspective of an exceptionally demanding national judge.
- Preserve student ownership and understanding of the research.

## Collaboration

Use separate branches for proposed changes. Run relevant tests before opening a pull request. Document modifications, evidence, limitations, and unresolved issues.

Update PROJECT_STATUS.md and CHANGELOG.md whenever major project milestones or decisions change.

Never commit API keys, passwords, or private credentials.
